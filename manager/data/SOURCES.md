# Источники и ограничения мировой футбольной базы

Срез сформирован для прототипа GameFootball (ноябрь 2026). Никаких платных API-ключей, скопированных платных составов, чужих фотографий или эмблем в репозитории нет. Источники ниже — CC0 (public domain); проверяйте исходные лицензии при обновлениях.

## 1. Клубы: 2 710 архивных записей

- Репозиторий: https://github.com/openfootball/clubs
- Источник: `SUMMARY.md`, 98 файлов по странам/регионам; формат: название клуба
- Файл проекта: `world-club-archive.json`
- Лицензия: CC0 1.0
- ВАЖНО: клубные названия могут быть историческими, включая переименованные или закрытые клубы. Наличие в архиве не означает участие в дивизионе в 2026 году.

## 2. Чемпионаты: 104 документированные записи сезонов

Файлы: `leagues-*.json` (14 фрагментов) — список лиг с датой сезона, страной, регионом, уровнем, источником и перечислением участвовавших клубов.

Источники:
- Европа: https://github.com/openfootball/europe
- Англия: https://github.com/openfootball/england
- Германия: https://github.com/openfootball/deutschland
- Испания: https://github.com/openfootball/espana
- Италия: https://github.com/openfootball/italy
- Австрия: https://github.com/openfootball/austria
- Азия, Африка, Ближний Восток, Северная/Центральная Америка, Океания: https://github.com/openfootball/world
- Южная Америка: https://github.com/openfootball/south-america

104 разные дивизионные записи, не обязательно все за одну дату. Полные списки участников: **100**. Неполные: **4** (Нидерланды, второе деление Нигерии, ЮАР, Австралия). Они отмечены `clubsComplete:false`. Для них показываем подтверждённые клубы, не выдумывая остальные.

Лицензия: CC0 1.0. Данные включают сезоны **2024–25, 2025, 2025–26, 2026 и 2026–27**, определяемые в каждом объекте `season`. Не следует выдавать список 2024/25 за актуальный 2026/27.

## 3. Игроки: 1 248 футболистов ЧМ-2026

- Источник: https://github.com/openfootball/worldcup.json/blob/master/2026/worldcup.squads.json
- Файл проекта: `worldcup-2026-club-players.json`
- Лицензия: CC0 1.0
- Исторический срез: 48 сборных × 26 игроков = 1 248 футболистов. Содержит имя, дату рождения, игровую роль, сборную, номер сборной, а также клуб на момент турнира; 451 сочетание клуб/страна.
- Это лишь часть профессионального футбола — НЕ все игроки этих клубов. После ЧМ возможны трансферы. Номер — из сборной, не гарантированно клубный.
- `world-data.js` объединяет одноимённые клубы внутри страны, прикрепляет только известных игроков и оставляет прочие составы пустыми.
- В игровой карьере фактические имена/возраст/позиции берутся из этого источника; **рейтинги/потенциал — игровые оценки, не реальные статистические данные**.
- Для вратарей пока доступны только симулируемые моменты, а не ручное управление.

## Чего не хватает для «каждого игрока каждой команды»

Нужен лицензированный и обновляемый источник **club squad roster** с идентификатором команды, идентификатором игрока и датами переходов. Отдельные публичные идентификационные реестры, даже на миллионы игроков, не дают достоверной современной привязки каждого человека к каждому клубу. Нельзя честно автоматически заполнить отсутствующие данные случайными футболистами.

План обновления: новый официальный/CC0/лицензированный источник → нормализация идентификаторов и названий клубов → проверка на дубль и даты → контроль полноты по чемпионатам → сохранение нового снапшота → автоматические тесты. У каждого нового источника сохранять дату, лицензию и ссылку. Для официальных логотипов/портретов потребуются отдельные права.
