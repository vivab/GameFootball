# ⚽ GameFootball

Мобильный 2D-футбол с видом сверху. Вдохновлён динамичными футбольными аркадами, но с собственным оформлением.

## MVP 0.1 — что готово
- Поле, две команды, ворота, табло и таймер на 3 минуты.
- Физика мяча: инерция, силовые удары, точные передачи, отскоки, контроль мяча и голы через углублённые ворота с сеткой.
- Три отдельные кнопки: **Держать мяч** (контроль при дриблинге), **Удар** (зарядка силой от короткого до мощного и менее точного) и **Пас** (слабее, зато точнее; пасом тоже можно забить). На ПК: WASD/стрелки, Shift (держать мяч), пробел (удержать/отпустить для удара), E (пас).
- Тренировка 5 на 5: ваш игрок и 4 напарника против 5 ботов — работает без сервера.
- Скорость игроков снижена до 185 условных единиц/с.
- Онлайн-комнаты по коду для **двух живых игроков**, остальные места в командах 5 на 5 занимают боты. Сервер рассчитывает все три действия и голы.
- Авторитетный WebSocket-сервер: счёт и физика рассчитываются на сервере.

## Локальный запуск
Нужен Node.js 20+. В корневой папке репозитория:

```bash
npm install
npm start
```

Откройте http://localhost:3000 в двух вкладках. Первый игрок создаёт комнату, второй вводит код.

## Как запустить онлайн для игры с разных телефонов
Разместите Node.js-приложение на сервисе с WebSocket-поддержкой, например Render Web Service:
- Repository: `vivab/GameFootball`
- Build command: `npm install`
- Start command: `npm start`
- Health check path: `/health`
- Для GitHub Pages в поле «Адрес игрового сервера» укажите `wss://ваш-домен-сервера`.

**Важно:** серверный код уже в репозитории, но хостинг ещё не настроен. Пока нет живого публичного WebSocket-сервера, онлайн через GitHub Pages не подключится.

## Камера и удары (обновление v5)
- Камера **следит за вашим игроком**, показывая лишь ближайшую часть поля. Работает как в одиночной тренировке, так и в сетевом матче, когда сервер запущен.
- Если мяч находится за пределами видимой области, у края экрана отображается значок **⚽ и стрелка** в его направлении (число рядом — приблизительное расстояние в игровых единицах).
- Удары значительно усилены: быстрое нажатие — мощный удар, удержание — ещё более сильный, но с некоторым разбросом. Пас остаётся точнее и слабее удара.
- Гол фиксируется **сразу при пересечении линии ворот** внутри проёма, а не после попадания мяча в заднюю сетку. Убрана лишняя вертикальная разметка у ворот.
- Игровое поле остаётся большим, но не уменьшается до размера мини-карты.

## Физика и ИИ v6 — исправления нестабильного мяча
- Клиент и Node.js-сервер используют **один общий модуль** `shared/football-core.js`: одинаковые правила на всех платформах.
- Мяч движется с собственными скоростью и импульсом. Дриблинг корректирует его скорость, **не переставляя мгновенно** перед игроком. Удары также не телепортируют мяч.
- Несколько ботов не могут одновременно бесконтрольно ускорять мяч: за микрошаг разрешается только одно наиболее глубокое столкновение, с ограниченным импульсом и скоростью.
- Команда выбирает **одного преследующего мяч** с гистерезисом, а другие поддерживают атаку, занимают линии передач или защищают ворота.
- Передачи и удары ИИ не происходят каждую долю секунды: используются задержки командных действий, роли, давление соперника и время контроля мяча.
- Отображение онлайн-матча плавно интерполируется между серверными снимками без вмешательства в авторитетную физику.
- **Проверки:** `npm test` запускает тесты на отсутствие телепортации при ведении и ударах, угловые столкновения, голы с обеих сторон, распределение ботов и долгую симуляцию.

Браузерная тренировка доступна через GitHub Pages. Для игры двух людей через интернет по-прежнему требуется развернуть отдельный Node.js WebSocket-сервер.
